# Checklist usability screenshots

Baseline: `8ee2f5431e8deff8dac4f0c4986b26fff8b047f8`. The old template-editor view is its metadata-only Edit dialog; there was no question-opening route. Read-only/narrow access can intentionally show Not found.

160 layout checks plus 20 settings viewport checks; no page overflow. 144 images: before/after at 1440×900, 1280×650 (device scale 1.5), 768×1024 and 390×844. 1920×1080 is checked without an image. Both light/dark, quality manager Maria Santos and narrower role Joy Aquino are synthetic sample identities.

The settings sheet is captured at viewport height. Other screens use full-page captures. Fonts are verified loaded in both sources. See [verification](../checklist-usability.md).
